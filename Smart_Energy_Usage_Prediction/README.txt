HOW TO RUN

GOOGLE COLAB
1. Open Google Colab.
2. Upload Smart_Energy_Usage_Prediction.ipynb.
3. Upload smart_energy_usage_dataset.csv using the Files panel.
4. Run the notebook cells from top to bottom.

JUPYTER
Keep the notebook and CSV in the same folder.
Install packages if needed:
pip install pandas scikit-learn matplotlib

Only one CSV dataset is used.
